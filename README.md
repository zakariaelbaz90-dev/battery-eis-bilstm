# Bayesian Physics-Guided BiLSTM for Joint SoC/SoH Estimation from Raw EIS Spectra
https://doi.org/10.5281/zenodo.22724847
Code and trained models accompanying the manuscript submitted to Journal. This repository reproduces every reported number and figure
from the raw dataset.

## Repository structure

```
├── data/
│   └── leonardi_final.npz          # preprocessed [488,51,3] EIS tensor + labels
│                                     # (raw source: Leonardi et al. 2026, Mendeley
│                                     #  Data DOI 10.17632/g7ncmhrcrz.1)
├── notebooks/
│   ├── dataset_pre-traitement_.ipynb   # raw -> tensor preprocessing
│   ├── bilstm_degradation.ipynb        # C3 model, architecture, training loop
│   ├── bilstm_c5.ipynb                 # C5 (4-param ECM subset) variant
│   ├── ablation_mc_vs_det.ipynb        # MC-Dropout vs deterministic, calibration
│   ├── degradation_analysis.ipynb      # CL/LLI/LAM diagnostic evaluation
│   ├── runC_all_fixes.ipynb            # consolidated results / calibration
│   └── posenc_experiment.ipynb         # positional-encoding ablation
├── lopo_training.ipynb              # leave-one-protocol-out stress test (this work's
│                                     # Section 3.3 headline result), 3-5 seeds x
│                                     # {C1,C3} x {AP3-out,AP4-out}
├── results/
│   ├── bilstm_full_results/         # trained checkpoints + scalers, all 5 configs,
│   │                                 # all 8 LOCO folds (model_cellNN.pt, scalers.pkl)
│   ├── all_results.pkl              # per-fold metrics backing Table 3/4
│   ├── mc_vs_det_results.pkl        # backing Table 4 / Fig. 5
│   └── lopo_results_multiseed.pkl   # backing Table (LOPO) / Fig. 9
├── figures/                         # scripts that regenerate every figure from
│                                     # results/*.pkl (fig_tsweep, fig_lopo,
│                                     # fig_calibration, fig_ablation, etc.)
├── requirements.txt
└── README.md
```

## Reproducing the paper's claims

| Paper item | Source |
|---|---|
| Table 3 (5-way factorial, LOCO) | `results/all_results.pkl`, generated by `notebooks/bilstm_degradation.ipynb` + `bilstm_c5.ipynb` |
| Table 4 / Fig. 5 (MC-Dropout vs deterministic) | `results/mc_vs_det_results.pkl`, `notebooks/ablation_mc_vs_det.ipynb` |
| Fig. 6 (T-sweep) | re-inference on saved C3 checkpoints, T in {1,5,10,25,50}, 3 seeds; see `figures/tsweep.py` |
| Fig. 7 (calibration / ECE) | `figures/calibration_figure.py`, run on saved C1/C3 checkpoints |
| Section 3.3 / Fig. 9 (LOPO stress test) | `lopo_training.ipynb` — trains new models from scratch (both cells of a protocol held out), 5 seeds x {C1,C3} x {AP3-out,AP4-out}; results in `results/lopo_results_multiseed.pkl` |
| Fig. 10 (degradation diagnostics) | `notebooks/degradation_analysis.ipynb` |

## Data availability

The raw EIS dataset is not redistributed here; it is publicly available from
Leonardi et al. (Mendeley Data, DOI: 10.17632/g7ncmhrcrz.1). `data/leonardi_final.npz`
is our preprocessed tensor built from that source, included for convenience and
exact reproducibility of the preprocessing step described in Section 2.2.
